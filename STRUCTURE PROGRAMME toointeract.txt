Système de gains - Moteur Hybride 40/60
4 Packs d'interaction (InteractionCategoriesPage.jsx + PoolsPage.jsx) :
PackBudget G (DT)Pool A (40%)Pool B (60%)Coeff. PBInteractions ciblesÉclat ?5 0002 0003 0000,000349%2 200 000Expansion ??10 0004 0006 0000,000174%4 200 000Prestige ??15 0006 0009 0000,000116%6 500 000Absolu ??20 0008 00012 0000,000087%8 500 000Pool A - Physique (40% de G) :
* Gain FIXE : 0,1 DT par interaction
* Support : écrans DOOH + scan QR Code
* Interactions max = poolAMass / 0.1 (ex: 8000 / 0.1 = 80 000)
Pool B - Digital (60% de G) :
* Gain DÉGRESSIF (Asymptotic Decay Model)
* Algorithme : Gain B = Solde restant × PB
* Ex: Interaction 1 = 12 000 × 0,000087% = 0,01044 DT
* Le gain diminue progressivement, jamais zéro abrupt
Fonction de calcul (PoolsPage.jsx, InteractionCategoriesPage.jsx) :
function computePools(G, pbCoeff) {
  const poolAMass = G * 0.4;                              // 40% de G
  const poolBMass = G * 0.6;                              // 60% de G
  const poolAInteractions = Math.round(poolAMass / 0.1);  // 0,1 DT fixe
  const firstGainB = poolBMass * (pbCoeff / 100);         // 1er gain dégressif
  return { poolAMass, poolBMass, poolAInteractions, firstGainB };
}
Types de campagnes
Phygital (CampaignsPage.jsx) :
* Écrans physiques (DOOH) + plateforme web
* Budget G divisé : 40% Pool A (fixe 0,1 DT) + 60% Pool B (dégressif)
* pool_type = 'both'
* QR code activable
Digital (CampaignsPage.jsx) :
* Plateforme web uniquement
* 100% du budget G en Pool B (dégressif)
* pool_type = 'pool_b', pool_a_gain_dt = 0
* Pas de QR code ni d'écrans physiques
Calcul du gain à la collecte (WatchEarn.jsx - handleCollect)
// 1. Récupérer la catégorie d'interaction de la campagne
const cat = await InteractionCategory.filter({ id: campaign.interaction_category_id });

// 2. Coefficient PB du pack (fallback si non configuré)
const pbCoeff = (cat.pb_coefficient || PACK_PB_FALLBACK[cat.code]) / 100;

// 3. Masse Pool B selon le type de campagne
const isDigital = campaign.campaign_type === 'digital';
const poolBMass = isDigital
  ? campaign.budget_dt                    // Digital: 100% du budget
  : campaign.budget_dt * 0.6;            // Phygital: 60% du budget

// 4. Somme des gains bruts déjà distribués
const existing = await Interaction.filter({ campaign_id, status: 'completed' });
const previousGrossSum = existing.reduce((s, i) => s + i.gain_earned_dt / 0.95, 0);

// 5. Gain dégressif = solde restant × PB
const remainingMass = Math.max(0, poolBMass - previousGrossSum);
const grossGain = remainingMass * pbCoeff;

// 6. Net = brut - 5% commission plateforme
const netGain = grossGain - grossGain * 0.05;
Créditation des gains (WatchEarn.jsx - createInteraction)
// Citoyen reçoit le gain NET
wallet.balance_dt += netGain;
wallet.total_earned_dt += netGain;
wallet.total_interactions += 1;
wallet.platform_commission_dt += grossGain * 0.05;  // commission tracée

// Commerçant affilié reçoit 5% du gain net du citoyen
const referrals = await Referral.filter({ referred_id: user.id, status: 'active' });
if (referrals.length > 0) {
  const merchantGrossGain = netGain * 0.05;
  const affiliationCommission = merchantGrossGain * 0.05;  // 5% plateforme
  const merchantNetGain = merchantGrossGain - affiliationCommission;

  merchantWallet.balance_dt += merchantNetGain;
  merchantWallet.affiliation_earnings_dt += merchantGrossGain;
  merchantWallet.platform_commission_dt += affiliationCommission;
}

Système de Bons Cadeaux (Voucher entity)
Valeurs fixes : 25, 50, 100, 200 DT - pas d'expiration
Circuit complet :
1. Annonceur configure les valeurs (VouchersPage.jsx)
   ? Voucher.create({ status: 'issued', entrepreneur_id, value_dt })

2. Citoyen extrait un bon (WalletPage.jsx)
   ? real_value_dt = value_dt × 0.9  (-10% commerçant)
   ? remaining_value_dt = value_dt × 0.9
   ? status: 'extracted', face_match_verified: true

3. Commerçant valide le bon (MerchantDashboard.jsx)
   ? commission = value_dt × 0.10  (10% pour le commerçant)
   ? status: 'used', merchant_id set
   ? wallet.voucher_commission_dt += commission

4. Commerçant transfère à l'annonceur (MerchantVouchersPage.jsx)
   ? Direct: entrepreneurAmount = remaining_value_dt
   ? Grossiste: wholesalerDeduction = remaining × 0.1
                entrepreneurAmount = remaining × 0.9
   ? status: 'returned', returned_to_entrepreneur: true
   ? entrepreneurWallet.returned_vouchers_value_dt += entrepreneurAmount
